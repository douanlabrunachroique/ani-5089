Méthode

Durée d'une image = 1000 / f (en ms), où f est la fréquence en Hz.
Budget restant pour le code = Durée d'une image − 8 ms.

Calculs
72 Hz
Durée d'une image : 1000 / 72 = 13,888... ms ≈ 13,9 ms
Budget restant : 13,9 − 8 = 5,9 ms

90 Hz
Durée d'une image : 1000 / 90 = 11,111... ms ≈ 11,1 ms
Budget restant : 11,1 − 8 = 3,1 ms

120 Hz
Durée d'une image : 1000 / 120 = 8,333... ms ≈ 8,3 ms
Budget restant : 8,3 − 8 = 0,3 ms
